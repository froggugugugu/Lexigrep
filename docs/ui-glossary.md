# UI 用語集

> Apple HIG に沿った標準を定義する。新しいラベルは先にここへ追加する。

## ボタンラベル標準

| 操作                   | 標準ラベル               | NG 例                    | 根拠                                 |
| ---------------------- | ------------------------ | ------------------------ | ------------------------------------ |
| 学習を始める(主導線)   | セッションを始める       | この題材で学習する       | 同じ操作は同じ語にする               |
| 学習を始める(行の中)   | 始める                   | 学習                     | 動作を示す動詞にする                 |
| 回答を進める           | 次へ / 完了              | 進む、終了               | 最後の 1 問だけ「完了」              |
| 設定を保存             | 保存                     | 保存する、セーブ         | 具体的で短い動詞                     |
| 間違いを報告           | 報告                     | 報告する                 | ボタンは体言止めに揃える             |
| 失敗した処理をやり直す | 再試行                   | もう一度、リトライ       |                                      |
| 記録画面へ移動         | 記録を見る               | ダッシュボードを見る     | タブ名と同じ語にする                 |
| ホームへ移動           | ホームに戻る             | ホームへ、ホームへ戻る   |                                      |
| 確認ダイアログの取消   | キャンセル               | 戻る、いいえ             | 標準の語を使う                       |
| アカウント削除の確定   | 削除                     | OK、はい                 | 「OK」ではなく動詞にする             |
| アカウント削除の起動   | アカウントとデータを削除 | 退会                     | 対象を明示する                       |
| ログイン / ログアウト  | ログイン / ログアウト    | サインイン、サインアウト |                                      |
| 紹介ページへ移動       | 使い方を見る             | ヘルプ、About、詳しく    | 行き先の見出し(使い方)と同じ語にする |
| 紹介ページから学習へ   | 始める                   | はじめる、スタート       | 行の中の「始める」と同じ語にする     |

処理中の表示は「〜中…」(保存中…、送信中…、削除中…)に統一する。

## ページタイトル標準

| 画面         | 形式           | 例                             |
| ------------ | -------------- | ------------------------------ |
| タブの最上位 | タブ名と同じ   | ホーム、題材、辞書、記録、設定 |
| 詳細画面     | 対象の名前     | TypeScript、deprecated         |
| 完了画面     | [対象]完了     | セッション完了                 |
| エラー       | 状況を述べる文 | ページが見つかりません         |
| 紹介ページ   | 使い方         | 使い方(`/about`。ログイン不要) |

## 名前の表示標準

| 対象         | 標準                                                | NG                                                 |
| ------------ | --------------------------------------------------- | -------------------------------------------------- |
| 題材         | `subject.name`(例: TypeScript)                      | `subject_id`(例: typescript)をそのまま             |
| ベースコース | `site.config.ts` の `baseCourse`                    | 全題材                                             |
| 層           | `LAYER_LABELS` の語(`system_term` は「題材特有語」) | 特有語・システム特有語(略称・旧称を画面で使わない) |
| 枚数・語数   | 数字 + 半角スペース + 単位(12 枚)                   | 12枚                                               |
| 進捗の比     | `6 / 12`                                            | `6/12`                                             |
| 日付         | `Intl.DateTimeFormat`(ja-JP)                        | ISO 文字列の切り出し                               |

## アイコン使用標準

SF Symbols と SF フォントのライセンスは Apple プラットフォーム向けなので、Web では使わない。
形を SF Symbols の慣習に合わせたインライン SVG を使う。アイコンライブラリは導入しない。

| 対象     | 形               | 必須 / 推奨 |
| -------- | ---------------- | ----------- |
| ホーム   | 家               | 必須        |
| 題材     | 重ねた本         | 必須        |
| 辞書     | 虫眼鏡           | 必須        |
| 記録     | 棒グラフ         | 必須        |
| 設定     | 歯車             | 必須        |
| 戻る     | 左向きシェブロン | 必須        |
| 行の遷移 | 右向きシェブロン | 必須        |
| 選択中   | チェックマーク   | 必須        |
| 閉じる   | ×                | 必須        |

タブの選択中は塗りつぶし、非選択は線画にする。

## 通知メッセージ標準

| 種別 | 形式                                | 例                        |
| ---- | ----------------------------------- | ------------------------- |
| 成功 | [名詞]を[動詞]しました              | 進捗を保存しました        |
| 失敗 | [名詞]の[動詞]に失敗しました        | 回答の保存に失敗しました  |
| 確認 | [名詞]を[動詞]しますか?             | アカウントを削除しますか? |
| 空   | [名詞]がありません + 次にできること | 該当する語句がありません  |
